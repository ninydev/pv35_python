# Social API (FastAPI)

Це проект на FastAPI з використанням SQLAlchemy 2.0, Loguru та Alembic.

## Як запустити

1. **Клонуйте репозиторій.**
2. **Налаштуйте змінні оточення:**
   Створіть файл `.env` на основі прикладу (якщо він відсутній).
3. **Запустіть базу даних:**
   ```bash
   docker-compose up -d
   ```
4. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```
5. **Запустіть миграції:**
   ```bash
   alembic upgrade head
   ```
6. **Запустіть додаток:**
   ```bash
   uvicorn src.main:app --reload
   ```

## Структура проекту

- `src/config`: Конфігурація додатка та логування.
- `src/infrastructure`: Налаштування бази даних та базові моделі.
- `src/features`: Модулі (фічі) проекту.
  - `auth`: Аутентифікація та RBAC.
  - `health`: Актуатор (перевірка стану системи).
- `migrations`: Міграції бази даних (Alembic).

## Ендпоінти

- `/auth`: Реєстрація, логін, профіль.
- `/health`: Стан бази даних, пам'яті та диска.
- `/docs`: Swagger документація.
