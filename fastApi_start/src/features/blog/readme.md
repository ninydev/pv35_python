# Модуль Блогу (Агрегація)

Цей модуль призначений для агрегації контенту користувача з різних частин системи.

### Основні можливості:
- **Персональна сторінка**: Отримання всіх постів конкретного користувача в одному запиті.
- **Повна інформація**: Кожен пост в агрегованому списку вже містить лічильник лайків та список коментарів.
- **Пагінація**: Підтримка пагінації для персональних стрічок постів.

### API:
- `GET /blog/user/{user_id}` — Стрічка постів конкретного автора.

### Технічні деталі:
Модуль використовує `PostService` для збору даних, забезпечуючи високу швидкість відповіді за рахунок оптимізованих запитів (selectinload).
