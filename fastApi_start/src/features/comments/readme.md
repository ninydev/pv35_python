# Модуль Коментарів

Цей модуль відповідає за управління коментарями до постів у соціальній мережі.

### Основні можливості:
- **Створення коментарів**: Авторизовані користувачі можуть залишати коментарі до будь-якого існуючого поста.
- **Зв'язок з автором**: Кожен коментар зберігає посилання на користувача, який його створив.
- **Зв'язок з постом**: Коментарі жорстко прив'язані до постів і автоматично видаляються при видаленні поста (cascade delete).

### Технічні деталі:
- **Модель**: `Comment` з полями `post_id`, `author_id` та `content`.
- **API**: 
    - `POST /comments/{post_id}` — Додати коментар до конкретного поста.

### Стандарти:
- Використовується асинхронна робота з БД через SQLAlchemy 2.0.
- Валідація вхідних даних через Pydantic.
