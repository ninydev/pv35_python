# Модуль WebSocket (Real-time Chat)

Цей модуль демонструє можливості двостороннього зв'язку в реальному часі за допомогою протоколу WebSocket у FastAPI.

### Основні можливості:
- **Двосторонній зв'язок**: На відміну від SSE, WebSocket дозволяє як серверу надсилати дані клієнту, так і клієнту серверу через одне відкрите з'єднання.
- **Глобальний чат**: Реалізовано простий механізм кімнати чату, де повідомлення від одного користувача миттєво бачать всі інші.
- **Системні сповіщення**: Сервер автоматично сповіщає всіх учасників про приєднання або вихід користувачів.
- **WebSocketManager**: Централізований клас для керування активними з'єднаннями та розсилки повідомлень (broadcast).

### Технології:
- **FastAPI WebSocket**: Вбудована підтримка протоколу WebSocket.
- **Python-Logging**: Логування підключень та помилок.

### Як це працює:
1. Клієнт підключається до сервера:
   ```javascript
   const socket = new WebSocket('ws://localhost:8000/ws/chat/1');
   
   socket.onmessage = (event) => {
       const data = JSON.parse(event.data);
       console.log('Повідомлення:', data.message);
   };
   
   // Відправка повідомлення на сервер
   socket.send('Привіт всім!');
   ```
2. Сервер зберігає об'єкт `WebSocket` у списку активних підключень.
3. При отриманні тексту від клієнта, сервер ітерує по всіх активних з'єднаннях і розсилає JSON-повідомлення.

### Чому WebSocket краще за SSE в даному випадку?
- **SSE** — це односторонній канал (Сервер -> Клієнт). Для відправки повідомлення назад на сервер (Chat message) довелося б робити додатковий HTTP POST запит.
- **WebSocket** — дозволяє відправляти повідомлення в обидва боки миттєво, що критично для чатів та ігор.
