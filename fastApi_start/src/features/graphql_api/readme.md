# Модуль GraphQL API

Цей модуль демонструє можливості технології GraphQL для сучасних веб-додатків. GraphQL надає клієнту можливість точно описати, які дані йому потрібні, уникаючи зайвих запитів до сервера.

### Переваги GraphQL для студентів:
- **Гнучкість**: Фронтенд може запитувати тільки ті поля, які йому потрібні зараз.
- **Один ендпоінт**: Замість десятків REST маршрутів — один `/graphql`.
- **Типізація**: Сувора схема дозволяє уникнути помилок у форматі даних.
- **Агрегація**: Можливість отримати пост, його автора, лайки та коментарі в одному запиті (замість 3-4 REST запитів).

### GraphQL Playground
Для зручності навчання у проект інтегровано **Playground** — інтерактивне середовище для тестування запитів.
Ви можете відкрити його у браузері за адресою: `/graphql` (зазвичай `http://localhost:8000/graphql`)

### Приклад запиту (Query)
Скопіюйте цей код у Playground, щоб побачити магію GraphQL:

```graphql
query GetAllPosts {
  allPosts(limit: 5, offset: 0) {
    id
    content
    imageUrl
    createdAt
    likesCount
    author {
      id
      email
    }
    comments {
      id
      content
      author {
        email
      }
    }
  }
}
```

### Як це працює:
- Схема описана у файлі `src/features/graphql_api/schema.py` за допомогою бібліотеки `strawberry`.
- Запити обробляються асинхронно з використанням сесії бази даних, що передається через контекст.
- Модуль налаштований без авторизації для демонстраційних цілей, щоб студенти могли одразу протестувати запити.
