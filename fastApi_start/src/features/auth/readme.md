# Модуль автентифікації та RBAC

Цей модуль забезпечує ідентифікацію користувачів та контроль доступу на основі ролей (RBAC) з використанням JWT (JSON Web Tokens).

### Основні можливості:
- **Реєстрація користувачів**: Створення нового облікового запису з автоматичним призначенням ролі за замовчуванням (`user`).
- **Авторизація (Login)**: Отримання JWT токена за допомогою OAuth2 Password flow.
- **Отримання профілю (Me)**: Перегляд інформації про поточного авторизованого користувача.
- **RBAC (Role-Based Access Control)**: Захист ендпоінтів на основі ролей (`user`, `admin`).
- **Хешування паролів**: Безпечне збереження паролів з використанням алгоритму `bcrypt`.

### Технології:
- **FastAPI Security**: Використання `OAuth2PasswordBearer` та `OAuth2PasswordRequestForm`.
- **PyJWT**: Генерація та валідація JWT токенів.
- **Passlib**: Надійне хешування паролів.
- **SQLAlchemy 2.0 (Async)**: Робота з базою даних.

### Ролі:
За замовчуванням у системі передбачені дві ролі:
1. `user` — звичайний користувач.
2. `admin` — адміністратор із розширеними правами.

### Використання:
1. Виконайте миграції бази даних: `alembic upgrade head`.
2. Зареєструйтесь через `POST /auth/register`.
3. Отримайте токен через `POST /auth/login`.
4. Використовуйте отриманий токен у заголовку `Authorization: Bearer <token>` для доступу до захищених ресурсів.
