# Модуль Постів

Цей модуль є центральним елементом соціальної мережі, що забезпечує створення та перегляд контенту.

### Основні можливості:
- **Управління постами**: Створення текстових постів з завантаженням реальних зображень.
- **Завантаження файлів**: Використовується абстрактний сервіс сховища, що дозволяє зберігати файли локально або легко перемикатися на хмарні рішення (S3, Azure).
- **Пагінація**: Всі списки постів підтримують стандартну пагінацію (`page`, `size`), що дозволяє ефективно працювати з великими обсягами даних.
- **Детальний перегляд**: Отримання повної інформації про пост, включаючи автора, кількість лайків та список коментарів.

### Технічні деталі:
- **Модель**: `Post` зі зв'язками до `User`, `Comment` та `Like`.
- **Пагінація**: Повертає об'єкт з метаданими (`total`, `page`, `pages`, `next_page`, `prev_page`).
- **API**:
    - `POST /posts/` — Створити пост.
    - `GET /posts/` — Отримати всі пости (пагіновано).
    - `GET /posts/{id}` — Деталі поста.

### Інтеграція:
Модуль тісно взаємодіє з фічами `comments` та `likes` через зв'язки в базі даних та спільні схеми даних.
