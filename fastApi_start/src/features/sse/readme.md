# Модуль SSE (Server-Sent Events)

Цей модуль забезпечує передачу сповіщень у реальному часі від сервера до клієнта. Це стандартний підхід для реалізації "push" сповіщень у веб-додатках.

### Основні можливості:
- **Підписка на події**: Клієнт може відкрити постійне з'єднання за адресою `/sse/subscribe/{user_id}`.
- **Персональні сповіщення**: Можливість відправити повідомлення конкретному користувачу (наприклад, "ваш пост лайкнули").
- **Broadcast сповіщення**: Можливість відправити повідомлення всім активним користувачам одночасно.
- **Keep-alive**: Вбудований механізм підтримки з'єднання (ping) для запобігання розриву тайм-аутами проксі-серверів.

### Технології:
- **sse-starlette**: Бібліотека для зручної роботи з SSE у FastAPI/Starlette.
- **asyncio.Queue**: Використовується для асинхронної передачі повідомлень між сервісами та SSE-генератором.

### Як це працює:
1. Клієнт (фронтенд) створює об'єкт `EventSource` у JavaScript:
   ```javascript
   const eventSource = new EventSource('http://localhost:8000/sse/subscribe/1');
   eventSource.onmessage = (event) => {
       const data = JSON.parse(event.data);
       console.log('Нове сповіщення:', data);
   };
   ```
2. Сервер реєструє чергу (`asyncio.Queue`) для цього користувача в `SSEConnectionManager`.
3. Будь-який сервіс (Auth, Comments, Likes) може викликати `sse_manager.send_personal_message(user_id, data)` або `sse_manager.broadcast(data)`.
4. Повідомлення потрапляє в чергу і миттєво відправляється клієнту через відкрите SSE з'єднання.

### Реалізовані події:
- `new_user` — сповіщення всім про реєстрацію нового користувача.
- `new_like` — персональне сповіщення автору поста про новий лайк.
- `new_comment` — персональне сповіщення автору поста про новий коментар.
