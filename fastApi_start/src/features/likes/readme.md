# Модуль Лайків

Цей модуль реалізує систему вподобань (лайків) для постів.

### Основні можливості:
- **Toggle Like**: Користувач може поставити лайк посту. Якщо лайк вже існує, повторний запит його видалить.
- **Унікальність**: Один користувач може поставити лише один лайк одному конкретному посту (контролюється на рівні БД через `UniqueConstraint`).
- **Лічильник**: Система дозволяє отримувати загальну кількість лайків для поста.

### Технічні деталі:
- **Модель**: `Like` з полями `post_id` та `user_id`.
- **API**:
    - `POST /likes/{post_id}` — Поставити або прибрати лайк.

### Стандарти:
- Асинхронна архітектура.
- Використання `UniqueConstraint` для запобігання дублікатів.
