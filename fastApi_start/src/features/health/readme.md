# Моніторинг здоров'я проекту (Actuator)

Цей модуль надає API для перевірки стану системи за стандартами телеметрії. Він дозволяє відстежувати працездатність додатка та його ключових ресурсів.

### Основні показники:
- **Database Connection**: Перевірка можливості підключення до бази даних PostgreSQL.
- **Memory Usage**: Інформація про використання оперативної пам'яті (загальна, використана, вільна та відсоток використання).
- **Disk Usage**: Інформація про стан дискового простору в системі.

### Використання:
Запит на ендпоінт `GET /health` повертає JSON-об'єкт із поточними метриками. Це корисно для інтеграції з системами моніторингу (наприклад, Kubernetes Liveness/Readiness probes або Prometheus).
